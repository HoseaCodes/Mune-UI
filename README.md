## How to run project locally

- First install the dependencies with `npm install --legacy-peer-deps`
  note: --legacy-peer-deps flag is used if you are running react version 19, as Shadcn hasn't finished fully implementing their framework into React version 19. This is to prevent any dependency errors for certain components.
- After installing run `npm run dev`
- The app should now be running on your `localhost:3000`
